# Session Context: SDK Split (dart_sdk + flutter_sdk)

## Session ID
34444bc9-70ca-4c32-9705-4d3165304122

## Goal
Split the ABSmartly Flutter SDK into two packages:
1. **dart_sdk** - Pure Dart SDK with core A/B testing logic
2. **flutter_sdk** - Flutter wrapper with Flutter-specific conveniences

## Current State Analysis

### Codebase Statistics
- **Total files**: 67 Dart files in lib/

- **Flutter-dependent files**: 4 (6%)

### Flutter Dependencies (to be removed in dart_sdk)

| File | Usage |

### Replacement Strategy
Replace Flutter's foundation utilities with `package:collection`:
```dart
// Before (Flutter)
import 'package:flutter/foundation.dart';
listEquals(a, b);
mapEquals(a, b);

// After (pure Dart)
import 'package:collection/collection.dart';
const ListEquality().equals(a, b);
const MapEquality().equals(a, b);
```

## Architecture Decision

### Package Names (pub.dev)
| Package | pub.dev Name | Directory |
|---------|--------------|-----------|
| Pure Dart | `absmartly_dart` | `packages/dart_sdk/` |

```

│   ├── test/

│   └── README.md
│
└── flutter_sdk/                 # Flutter wrapper (publishes as absmartly_sdk)

    ├── example/                 # Flutter example app
    ├── pubspec.yaml
    └── README.md
```
